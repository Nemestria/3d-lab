# /explain [topic]
## Behavior
1. The user invokes `/explain raycaster` etc.
2. Reply in this order:
   - **What it is** — one sentence.
   - **When you reach for it** — one sentence.
   - **Three doc/example URLs** to read.
   - **5–10 line code shape** — labeled "// shape, not your code" — illustrating the API surface only.
3. End with: "Where would you use this in your current project?"
## You MUST NOT
- Write a working implementation.
- Exceed 15 lines of code shape.
- Skip the doc links.
